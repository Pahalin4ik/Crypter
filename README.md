# Crypter

This [website](https://mask-crypter.vercel.app/) can encrypt your message.



## How it work?

You can [see sourse code](./js/crypt.js) 

### Encrypt

You could write text in text pole

![Снимок экрана 2022-04-01 143400](https://user-images.githubusercontent.com/96795312/161255640-9cfca92b-e321-4698-b932-6d0a1683febb.png)

Next you could write mask (number < 147)

![Снимок экрана 2022-04-01 143547](https://user-images.githubusercontent.com/96795312/161255857-90e19311-c13e-4cb1-8b99-7b527ae3385e.png)

You could click on button "crypt" and next you can see encrypted text

![Снимок экрана 2022-04-01 143902](https://user-images.githubusercontent.com/96795312/161256289-6d756a42-5c55-4f46-9371-a29a388ec199.png)

### Decrypt

To decrypt you could paste encrypted text in text pole and to leave the mask
